Branding or Aesthetics of the Website:
Design the website using a modern SaaS-inspired landing page style with a clean, professional, and youthful look suitable for a student organization website.
The visual design should be inspired by modern startup websites with the following characteristics:
•	Clean white or very light gray background. 
•	Large bold hero headline at the center. 
•	Minimal navigation bar with rounded pill-style buttons. 
•	Soft blue, purple, and light gradient accents. 
•	Floating cards around the hero section showing important organization details. 
•	Subtle grid, dotted, or abstract background patterns. 
•	Soft shadows, rounded corners, and glassmorphism-style cards. 
•	Smooth hover effects and modern animations. 
•	Clear call-to-action buttons such as Join Now, Log In, View Activities, or Get Started. 
•	Fully responsive layout for desktop, tablet, and mobile. 
The overall mood should feel:
modern, clean, trustworthy, organized, student-friendly, and professional.
Landing Page Layout Style
The landing page should have a centered hero section similar to a modern SaaS website.
The top navigation should include:
•	Organization logo on the left. 
•	Navigation links in the center such as Home, About, Activities, Partners, Announcements, and Calendar. 
•	Login and Sign Up buttons on the right. 
The hero section should include:
•	A small badge above the title, such as “Official Student Organization Platform”. 
•	A large bold headline, for example:
Empowering Students Through Leadership, Service, and Community 
•	A short subtitle explaining the organization. 
•	Two call-to-action buttons: 
o	Join Now 
o	View Activities 
Around the hero text, add floating cards such as:
•	Upcoming Event card 
•	Active Members card 
•	Organization Officers card 
•	Announcement card 
•	Partner card 
These floating cards should have:
•	White or translucent background. 
•	Rounded corners. 
•	Soft shadows. 
•	Small icons. 
•	Short text. 
•	Slight rotation or offset position for a dynamic modern look. 
Background Design
Use a subtle decorative background:
•	Light grid pattern behind the hero section. 
•	Soft radial gradient glow using blue, purple, or yellow. 
•	Optional dotted texture pattern. 
•	Large abstract gradient circle or arc at the bottom of the hero section. 
•	Background should stay clean and not distract from the text. 
Do not make the design too colorful or crowded. Keep the design elegant and readable.
Color Palette
Use a modern color palette:
•	Primary color: royal blue or deep blue. 
•	Secondary color: purple or violet. 
•	Background: white, off-white, or light gray. 
•	Text: near-black or dark gray. 
•	Muted text: gray. 
•	Accent colors: light blue, lavender, and soft yellow. 
Example colors:
•	Primary Blue: #2563EB 
•	Deep Blue: #1E40AF 
•	Purple: #7C3AED 
•	Light Background: #F8FAFC 
•	Dark Text: #111827 
•	Muted Text: #6B7280 
•	Card Border: #E5E7EB 
Typography
Use a modern sans-serif font.
Recommended fonts:
•	Inter 
•	Geist 
•	Manrope 
•	Poppins 
Headings should be large, bold, and clean.
Body text should be readable, simple, and professional.
UI Component Style
Use the following component style:
•	Rounded buttons with smooth hover effects. 
•	Cards with border, shadow, and rounded-2xl. 
•	Glassmorphism effect for floating cards. 
•	Soft gradients for important buttons. 
•	Minimal icons using lucide-react. 
•	Consistent spacing and alignment. 
•	Mobile-first responsive layout. 
Dashboard Design Style
After login, the dashboard should still follow the same modern design style.
The dashboard should include:
•	Sidebar or top navigation. 
•	Greeting section. 
•	Member profile summary card. 
•	Important updates card. 
•	Announcements card. 
•	Activities card. 
•	Calendar preview card. 
•	My Registered Activities card. 
For regular members, show only member-accessible features.
For the President, Vice President for Internal Affairs, and Vice President for External Affairs, show an additional officer-only card or button:
Add Event / Program
This button should open or direct to an event creation form with:
•	Event / Program Name 
•	Date and Time 
•	Short Description 
•	Location 
Only users with the roles president, vp_internal_affairs, or vp_external_affairs should see and access this feature. Regular members must not see the button and must not be allowed to access the event form directly. This should be protected both in the frontend UI and backend Supabase Row Level Security rules. The site functions should follow the role-based features described in the uploaded website function document. 
Animation Style
Add subtle animations only:
•	Fade-in sections while scrolling. 
•	Floating card movement. 
•	Button hover scale. 
•	Card hover shadow increase. 
•	Smooth page transitions. 
Animations should be lightweight and should not slow down the website.
Design Direction Summary
Build the website as a modern student organization platform with the visual quality of a SaaS landing page. The design should combine:
•	Clean layout 
•	Bold typography 
•	Soft gradient background 
•	Floating information cards 
•	Rounded modern UI 
•	Professional dashboard 
•	Role-based officer controls 
•	Mobile responsiveness 
The website should look polished, modern, and credible while still being simple enough to maintain using Next.js, React, TypeScript, Tailwind CSS, Supabase, PostgreSQL, Supabase Auth, Supabase Storage, GitHub, and Vercel.
